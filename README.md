## 项目简介

School Smart+ · 智慧校园系统是一个多模块的应用程序，整合了校园内的各项服务，通过直观的界面与便捷的操作，用户可以实时监控校园环境、管理图书馆借阅、获取最新公告与活动信息、查询个人课程表以及管理个人校园资料。

---

## 功能概览

### 1. 校园环境监测  
- **环境数据展示**：实时显示教学楼、实验楼、宿舍楼、图书馆等地点的温度、湿度、二氧化碳浓度及安全预警（火焰、烟雾检测）。
- **自动刷新**：系统每 3 秒自动刷新监测数据，确保信息的时效性。

### 2. 个人中心  
- **用户信息管理**：展示用户头像、姓名、邮箱、电话及校园卡余额等信息。
- **智慧校园信息**：显示学号、专业、宿舍信息、图书馆状态、课程安排等校园相关数据。
- **操作按钮**：提供编辑资料与退出登录等功能。

### 3. 主页面与功能入口  
- **轮播图**：展示校园相关的横幅信息与活动宣传。
- **功能入口**：快速访问课程表、校园导航、图书馆、公告与活动等模块。
- **视频播放**：集成视频播放组件，支持自动播放、控制器操作及回调处理。

### 4. 图书馆管理  
- **图书列表**：展示书籍的标题、作者、借阅状态和推荐信息。
- **搜索功能**：支持根据书籍名称进行模糊搜索。
- **操作按钮**：根据书籍状态提供借阅或预约操作。

### 5. 校园公告与活动  
- **公告展示**：提供校园网络维护、运动会、招聘会等公告的详细信息。
- **活动报名与签到**：用户可以通过操作按钮进行活动报名与现场签到。

### 6. 课程表查询  
- **月份与星期切换**：支持用户在不同月份与星期之间切换，查看当天的课程信息。
- **课程详情**：展示课程名称、上课时间、地点及授课教师信息。

## 技术架构

本项目使用 ArkTS 语言及 ArkUI 框架进行开发，主要模块包括：

- **Index 模块**：作为应用的入口，使用 Tabs 组件实现多页面导航。
- **CampusEnvMonitor**：校园环境监测模块，实时获取并展示各地点的环境数据。
- **UserProfile**：用户个人信息页面，展示用户在校园系统中的详细资料。
- **Main**：主页面模块，集成搜索、轮播图、功能入口及视频播放组件。
- **LibraryPage**：图书馆管理页面，提供图书搜索、展示及借阅预约操作。
- **Notificationse**：校园公告与活动页面，提供最新公告展示及活动报名/签到功能。
- **TimetablePage**：课程表查询页面，支持月份和星期切换，展示当天课程信息。

1. **环境准备**  
   - 安装  DevEco Studio。  
   - 配置 对应版本的SDK。

2. **项目构建**  
   - 克隆项目：  
     ```bash
     git clone https://github.com/XXYoLoong/SchoolSmart.git
     ```

   - 执行构建命令。

3. **部署与运行**  
   - 在 HarmonyOS 模拟器或真实设备上部署运行。  
   - 启动应用后，系统默认进入首页并支持页面间的无缝跳转。

## 使用说明

- **导航操作**:  
  通过底部标签栏在“主页”、“监测”、“我的”等主要模块间切换，确保用户能够快速访问各项功能。

- **环境监测**:  
  自动刷新各地点的环境数据，点击每个卡片查看具体的环境参数与预警信息。

- **图书管理**:  
  在图书馆页面，用户可以通过搜索栏查找感兴趣的书籍，并根据图书状态进行借阅或预约操作。

- **公告与活动**:  
  查看最新公告详情，并在活动模块内报名或签到参与校园活动。

- **课程表查询**:  
  通过月份和星期按钮切换，查看当天的课程安排。点击返回按钮可返回上一页面。
